# Aegis Accell

Aegis Accell is an open-source epistemic resilience layer for AI-accelerated research environments.

It does not replace technical vulnerability tools. It instruments the human-tool research process around them.

The system helps researchers capture:
- assumptions
- uncertainty markers
- provenance trails
- contradictions
- analyst fatigue indicators
- failure markers
- unlearning prompts
- red-team checkpoints
- post-failure knowledge salvage workflows

The purpose is to make the knowledge process observable, auditable, and recoverable.

Initial MVP:
A local-first web application for creating a research session, adding claims and assumptions, marking uncertainty, attaching provenance, logging contradictions and failures, and exporting the full record as JSON and Markdown.
